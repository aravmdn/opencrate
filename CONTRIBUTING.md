# Contributing to OpenCrate

Thanks for helping make open music easier to find.

1. Fork the repository and create a focused branch.
2. Run `npm install` and copy `.env.example` to `.env.local`.
3. Make your change. Keep all audio sources rights-aware: a provider must expose an explicit download permission or compatible license.
4. Run `npm run lint` and `npm run build`.
5. Open a pull request describing the behavior and how you verified it.

Please do not submit stream-ripping integrations, DRM bypasses, search scrapers, or sources that distribute music without authorization.
